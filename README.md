# Major Project

A full-stack web application built with Node.js, Express.js and EJS templating engine following MVC architecture with MongoDB database integration.

## 🛠️ Tech Stack

- **Backend**: Node.js, Express.js
- **Templating**: EJS (Embedded JavaScript)
- **Database**: MongoDB & Mongoose
- **Frontend**: HTML, CSS

## 📁 Project Structure

```
Major-Project/
├── models/        # Mongoose database models
├── views/         # EJS templates (server-side rendered pages)
├── public/css/    # Stylesheets
├── init/          # Database initialization scripts
└── app.js         # Entry point
```

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/RahulSAxena2628/Major-Project.git

# Go to project directory
cd Major-Project

# Install dependencies
npm install

# Run the app
node app.js
```
